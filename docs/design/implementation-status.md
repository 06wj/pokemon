# 共生之境 · 当前实现

日期：2026-09-08。

已实现设计稿的 P0，并按后续要求加入雨、雪和积雪。首页默认进入箱庭；显式藏馆链接继续可用。

- 20 位固定居民，性格与兴趣、柔和的觅食／满足／探索／睡眠循环。
- 投果与有限自然落果、真实进食与礼让；点火与聚集；吸水、喷水润花与访客回应；闻花与喷嚏回应。
- 数据化动作序列、六种基础动画、有限事件感知、空间条件、取消／超时／重置清理。
- 相册与发现记录保存在当前浏览器；照片检查当前姿态和主体间遮挡，相册上限 12 张，容量不足不淘汰旧照片。
- 晴、雨、雪；渐进积雪、融化和湿润地面；个体化避雨、观察雨雪与取暖；照片保留天气信息。
- 跟随卡片提供明确的“取消跟随”，右下“全景”也能退出。

## 本轮生活细节

- 火、水、电效果配合观察、蓄势、触发与收势；皮卡丘会在合适空地做短暂电光小把戏。
- 局部事件让附近少数伙伴按距离、性格、困意与当前动作接戏，可转头、稍退或开心回应；每个信号有期限、回复数上限和冷却。
- 连续 Idle 步骤保持同一段动画播放，辅以轻微观察、准备、放松与睡眠呼吸姿态，不改变导航占地。
- 程序音效涵盖草地／沙地／水边脚步、落果和咬果、树叶、火气流、电噼啪、吸水和水花，以及克制的情绪短音。右上开关保存偏好，首次用户手势才解锁；暂停、初始化与后台状态会停掉音源，恢复不补播。
- 长期发现记录继续按稳定 ID 去重，近期事件另行记录实际发生时间与参与者；重复发生的小戏可以进入新照片的 Moment 标记，仍需参与者确实在当前画面可见。

长期关系记忆、更多地图、完整建造系统及复杂摄影评分尚未实现；设计目录中的 P1 小戏并非全部已完成。

## 验证

本轮 `npm run build`、`npm run test:ecology`、`npm run test:living` 已通过；测试套件新增局部反应、细微姿态与音频调度覆盖。火、水、电的反应瞬间在真正转头时即可被照片记录，首次收藏时间保持不变。

音频调度测试已通过，覆盖首次同步静默、步骤／落地去重、音源与脚步上限、暂停不补播、恢复后新声音、重开后复用 ID 以及销毁。独立真实浏览器检查确认手势前没有 AudioContext，可信指针手势后产生非零音频样本；暂停清空音源，恢复无旧音残留，销毁关闭上下文。真实 OfflineAudioContext 对 12 种声音的渲染均非零，测得最高峰值约 0.0611，未出现削波；这属于输出与生命周期验证，尚未进行人工音色验收。

本轮在独立 Chrome 中分别以 WebGL2 和 WebGPU 加载完整 20 位居民，验证声音首次手势解锁／静音／恢复、跟随与取消、暂停冻结、390px 布局和真实 JPEG 拍照；另检查 320px 按钮不会挤出画面。两种后端均渲染了自然行为触发的喷火、放电、水柱，喷火时卡比兽与鬼斯转头，水柱旁妙蛙种子与巴大蝶停步回应。画面检查通过本地测试驱动推进模拟时间，不代表多人或所有设备的性能验收。

WebGPU 整场景还验证雨／雪切换、积雪与融化、真正后台标签页停止时钟与声音，以及销毁后无居民、画布或音源残留。元素特效独立 WebGL2 检查覆盖触发前隐藏、暂停顶点冻结、中断主流与短尾迹、重开复用事件 ID、重复销毁。三类演出最多共用三个槽和八个网格批次，不为每条水柱或电弧新建独立场景节点。
