# 共生之境 · 当前实现

日期：2026-09-08。

已实现设计稿的 P0，并按后续要求加入雨、雪和积雪。首页默认进入箱庭；显式藏馆链接继续可用。

- 20 位固定居民，性格与兴趣、柔和的觅食／满足／探索／睡眠循环。
- 投果与有限自然落果、真实进食与礼让；点火与聚集；吸水、喷水润花与访客回应；闻花与喷嚏回应。
- 数据化动作序列、六种基础动画、有限事件感知、空间条件、取消／超时／重置清理。
- 相册与发现记录保存在当前浏览器；照片检查当前姿态和主体间遮挡，相册上限 12 张，容量不足不淘汰旧照片。
- 晴、雨、雪；渐进积雪、融化和湿润地面；个体化避雨、观察雨雪与取暖；照片保留天气信息。
- 跟随卡片提供明确的“取消跟随”，右下“全景”也能退出。

长期关系记忆、更多地图、完整建造系统及复杂摄影评分尚未实现；设计目录中的 P1 小戏并非全部已完成。

## 验证

`npm run build`、`npm run test:ecology`、`npm run test:living` 已通过。新增测试覆盖 20 居民长时间模拟、天气积融雪、暂停、真实消费、遮挡归属、收藏恢复和路由。

已在浏览器观察 20 位居民与实际互动，并验证 JPEG 拍照、保存与刷新恢复；雨、雪、积雪、光照响应、暂停和销毁另有独立 WebGL2 画面检查。最终整场景 WebGPU 及雨雪端到端手工回归尚未完成：内置浏览器控制超时，后续本机浏览器验证被用户操作打断。没有据此宣称所有 GPU 场景均已验收。
